gmail-expense プライバシーポリシー

最終更新日: 2026年10月10日

1. このアプリについて

gmail-expense は、開発者本人が自分専用に使う家計管理ツールです。一般には公開・配布しておらず、開発者本人以外は利用しません。

2. 取得する情報と、その使い道

本人が許可したGoogleアカウントのGmailから、注文確認・決済通知・カード利用通知などのメールを読み取り、購入日・金額・店名・商品名などを抽出します。抽出した情報は、本人の家計の記録(表計算ファイル)を作るためだけに使います。

3. 情報の保管と共有

  • 読み取った情報は、本人のパソコン内でのみ処理・保管します。
  • 外部のサーバーへ送信したり、第三者へ提供・販売・共有したりしません。
  • 広告の目的や、利用者の分析・プロファイリングには使いません。

4. Googleユーザーデータの扱い

本アプリによるGoogleユーザーデータの利用と、他のアプリへの受け渡しは、Google API サービスのユーザーデータに関するポリシー(限定的な使用の要件を含む)に従います。

5. 許可の取り消し

Googleアカウントの「アカウント設定 > セキュリティ > サードパーティのアプリとサービス」から、いつでもこのアプリへの許可を取り消せます。

6. 変更

このポリシーを変更する場合は、このページを更新します。

English summary

gmail-expense is a personal tool used only by its developer. It reads order and payment notification emails from the developer's own Gmail accounts, with the developer's consent, and compiles purchase information into a spreadsheet on the developer's own computer. Data is processed and stored only on that computer; it is not sent to any server, shared with or sold to third parties, or used for advertising. The app's use of Google user data complies with the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time from the Google Account security settings.
